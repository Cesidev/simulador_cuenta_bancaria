# 🏦 Sistema de Simulación de Cuenta Bancaria

Este es un programa interactivo escrito en **Python** que simula las operaciones básicas de una cuenta bancaria, aplicando los principios fundamentales de la **Programación Orientada a Objetos (POO)**.

## 📱 Reto de Desarrollo Especial
Este proyecto tiene un valor muy importante para mí: **fue programado en su totalidad desde un teléfono móvil**. Adaptarse a una pantalla táctil y gestionar el entorno de desarrollo en un dispositivo celular ha sido un reto que demuestra mi compromiso, disciplina y pasión por aprender a programar, superando cualquier limitación técnica.

## 🚀 Características
*   **Clases y Objetos:** Creación de instancias únicas para usuarios con atributos de titular y saldo.
*   **Encapsulamiento Lógico:** Métodos dedicados para operaciones clave: mostrar balance, depositar y retirar fondos.
*   **Simulación en Tiempo Real:** Uso de la librería `time` para emular tiempos de espera y respuestas de un servidor real.
*   **Control de Fondos:** Validación de seguridad que impide retiros si la cuenta no cuenta con saldo suficiente.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Python 3
*   **Entorno:** IDE Móvil
